Building Dense Memory with Evolving Rubrics

Goal: Build a dense memory system using FAISS-based dense retrieval, augmented with an Evolving Rubric layer inspired by RLER (Shao et al., 2025). The rubric system continuously refines retrieval quality by learning — from each retrieval cycle — what criteria actually distinguish useful from useless memories for a given query or session context.

Core Idea: KNN retrieval via FAISS gives you candidates ranked by embedding similarity. Evolving rubrics give you a second, semantically richer scoring pass that re-ranks and filters those candidates based on what the agent actually found useful, not just what was geometrically close in vector space. Rubrics evolve: they are generated by contrasting retrieved memories that were used vs. ignored, updated every retrieval cycle, and pruned when they stop discriminating.

Total Implementation: ~600 lines of core code across 8 modules

LLM Requirements for Rubric System

The evolving rubric system uses two LLM roles, consistent with the RLER paper's architecture:

Role Purpose Recommended Model Cost Profile
Rubric Generator (G_rubric) Creates new rubrics by contrasting retrievals gpt-4.1 or claude-3-5-sonnet Called once per retrieval cycle
Rubric Judge (JUDGE) Scores a memory against a rubric criterion gpt-4.1-mini or claude-3-haiku Called K × N times per search

The judge is called far more frequently than the generator, so use a cheaper/faster model for judging. If latency is critical, you can batch judge calls or cache them aggressively — memory content doesn't change, so JUDGE(r_k, memory_m) is deterministic and cacheable.

User Query
    │
    ▼
[Encode query]
    │
    ▼
[FAISS KNN] ──────────────────────────────────────► 50 raw candidates
    │                                                        │
    │                                                        ▼
    │                                         [RubricJudge scores each]
    │                                         S(q, mᵢ) = rubric score
    │                                                        │
    │                                                        ▼
    │                                         [Hybrid re-rank]
    │                                         final_score = α·emb + β·rubric
    │                                                        │
    ▼                                                        ▼
[Return top-k]◄────────────────────────────────────── sorted results
    │
    ▼
[Agent uses results, cites some memories, ignores others]
    │
    ▼
[RubricGenerator observes used vs. unused]
    │
    ├── Generate new positive rubrics (what made used memories good?)
    ├── Generate new negative rubrics (what made unused memories bad?)
    └── Update rubric buffer + variance filter

The Rubric Scoring Formula (from RLER)

For a query q and retrieved memory m, the rubric score is:

$$S(q, m) = \frac{\sum_{k=1}^{K} w_k \cdot \text{JUDGE}(r_k, m)}{\sum_{k: w_k > 0} w_k}$$

Where:

  • r_k — the k-th rubric criterion (a natural language assertion)
  • w_k — weight of rubric k (can be negative to penalize failure modes)
  • JUDGE(r_k, m) — LM judge returning {0, 0.5, 1} for how well memory m satisfies r_k
  • Denominator normalizes only over positive-weight rubrics

The final hybrid retrieval score blends embedding similarity with rubric score:

$$\text{score}_{\text{final}}(q, m) = \alpha \cdot \text{cosine}(q, m) + \beta \cdot S(q, m) + \gamma \cdot \text{recency}(m)$$

Default weights: α=0.50, β=0.35, γ=0.15

4. Phase 1: Encoding Engine

This phase is unchanged from the base plan. The encoder has no direct rubric dependency — rubrics operate at the search and scoring layer, not the embedding layer. However, the encoder is used to embed rubric criteria themselves when you want approximate rubric matching (see Phase 4).

Practice 1: Unified Encoder (Not Separate Doc/Query)

PySerini pattern: Separate DocumentEncoder and QueryEncoder classes

Better approach: Single encoder with role flag

Reason:

  • Same model for both (sentence-transformers, BGE, etc.)
  • Same pooling/normalization settings
  • Simpler to maintain
  • Less code duplication

What to build:

class DenseEncoder:
    def __init__(self, model_name: str, device: str = 'cuda:0'):
        self.tokenizer = AutoTokenizer.from_pretrained(model_name)
        self.model = AutoModel.from_pretrained(model_name).to(device)
        self.model.eval()
        self.device = device
        self.dimension = self.model.config.hidden_size

    def encode(self, texts: list[str] | str, batch_size: int = 32) -> np.ndarray:
        """
        Encode texts to L2-normalized vectors.
        Handles both single strings and lists.
        Returns: np.ndarray of shape (N, D), dtype float32
        """
        if isinstance(texts, str):
            texts = [texts]

        all_embeddings = []

        for i in range(0, len(texts), batch_size):
            batch = texts[i : i + batch_size]
            inputs = self.tokenizer(
                batch,
                padding=True,
                truncation=True,
                max_length=512,
                return_tensors='pt'
            )
            inputs = {k: v.to(self.device) for k, v in inputs.items()}

            with torch.no_grad():
                outputs = self.model(**inputs)

            embeddings = self._mean_pool(
                outputs.last_hidden_state,
                inputs['attention_mask']
            )
            embeddings = embeddings.cpu().numpy().astype('float32')
            embeddings = self._normalize(embeddings)
            all_embeddings.append(embeddings)

        return np.vstack(all_embeddings)

Key decisions:

  • Model choice: BAAI/bge-m3 (strong multilingual, 1024-dim) or sentence-transformers/all-MiniLM-L6-v2 (fast, 384-dim)
  • Pooling: Mean pooling for sentence-transformers models
  • Normalize: Always True (for cosine similarity with IndexFlatIP)
  • Batch size: 32–64 for memory efficiency

Practice 5: Pooling Implementation

Mean pooling (recommended for sentence-transformers):

def _mean_pool(
    self,
    last_hidden_state: torch.Tensor,   # (batch, seq_len, hidden_dim)
    attention_mask: torch.Tensor       # (batch, seq_len)
) -> torch.Tensor:
    # Expand mask to match hidden state dimensions
    mask_expanded = (
        attention_mask
        .unsqueeze(-1)
        .expand(last_hidden_state.size())
        .float()
    )
    # Zero out padding positions
    masked = last_hidden_state * mask_expanded
    # Sum over sequence, then average over non-padding tokens
    sum_emb = torch.sum(masked, dim=1)
    sum_mask = torch.clamp(mask_expanded.sum(dim=1), min=1e-9)
    return sum_emb / sum_mask

CLS pooling (for BERT-style models):

def _cls_pool(self, last_hidden_state: torch.Tensor) -> torch.Tensor:
    return last_hidden_state[:, 0, :]

Practice 6: L2 Normalization

def _normalize(self, embeddings: np.ndarray) -> np.ndarray:
    norms = np.linalg.norm(embeddings, axis=1, keepdims=True)
    return embeddings / np.maximum(norms, 1e-9)

5. Phase 2: Storage & Indexing

The original storage design is extended with a rubric buffer table in the same SQLite database. FAISS stores vectors only. SQLite stores two things: (1) memory metadata, (2) the rubric buffer — both persistent and active rubric sets per query/session.

Practice 2A: FAISS Index Wrapper

import faiss
import numpy as np

class DenseVectorIndex:
    """
    Wraps a FAISS index with docid mapping.
    FAISS knows nothing about metadata or rubrics — that stays in SQLite.
    """

    def __init__(self, dimension: int = 384, index_type: str = 'flat'):
        self.dimension = dimension
        self.docids: list[str] = []
        self.index = self._create_index(index_type)

    def _create_index(self, index_type: str):
        if index_type == 'flat':
            return faiss.IndexFlatIP(self.dimension)
        elif index_type == 'hnsw':
            idx = faiss.IndexHNSWFlat(self.dimension, 32)  # M=32
            idx.hnsw.efConstruction = 40
            return idx
        else:
            raise ValueError(f"Unknown index type: {index_type}")

    def add(self, vectors: np.ndarray, doc_ids: list[str]):
        """Add vectors with their string IDs."""
        assert vectors.shape[1] == self.dimension, "Dimension mismatch"
        vectors = vectors.astype('float32')
        self.index.add(vectors)
        self.docids.extend(doc_ids)

    def search(self, query_vec: np.ndarray, k: int = 50) -> list[dict]:
        """
        Raw KNN search — returns candidates for rubric re-ranking.
        Deliberately over-retrieves (default k=50) to give rubric layer headroom.
        """
        if query_vec.ndim == 1:
            query_vec = query_vec.reshape(1, -1)
        query_vec = query_vec.astype('float32')

        scores, indices = self.index.search(query_vec, k)

        results = []
        for score, idx in zip(scores.flat, indices.flat):
            if idx >= 0:
                results.append({
                    'id': self.docids[idx],
                    'embedding_score': float(score)
                })
        return results

    def save(self, path: str):
        faiss.write_index(self.index, f'{path}/index.faiss')
        with open(f'{path}/docids.txt', 'w') as f:
            for doc_id in self.docids:
                f.write(f'{doc_id}\n')

    def load(self, path: str):
        self.index = faiss.read_index(f'{path}/index.faiss')
        with open(f'{path}/docids.txt', 'r') as f:
            self.docids = [line.strip() for line in f]
        assert len(self.docids) == self.index.ntotal

Practice 2B & 8: Metadata Store with Rubric Buffer Tables (EXTENDED)

This is where the rubric layer gets its persistent storage. The SQLite database now has three tables:

  1. memories — existing memory records
  2. rubric_buffer_persistent — initial search-grounded rubrics (never deleted) ← NEW
  3. rubric_buffer_active — evolving session/query rubrics (pruned by variance) ← NEW
import sqlite3
import json
import datetime
from typing import Optional

class DenseMetadataStore:
    """
    SQLite-backed store for:
    - Memory metadata (text, user, session, timestamps, importance, etc.)
    - Persistent rubric buffer (initial search-grounded criteria per query)
    - Active rubric buffer (session-evolving criteria, pruned by variance)
    """

    def __init__(self, db_path: str = 'memory.db'):
        self.db_path = db_path
        self.conn = sqlite3.connect(db_path, check_same_thread=False)
        self._create_tables()

    def _create_tables(self):
        cursor = self.conn.cursor()

        # ── Original memory metadata table ──────────────────────────────────
        cursor.execute("""
            CREATE TABLE IF NOT EXISTS memories (
                id           TEXT PRIMARY KEY,
                text         TEXT NOT NULL,
                user_id      TEXT,
                session_id   TEXT,
                timestamp    DATETIME DEFAULT CURRENT_TIMESTAMP,
                memory_type  TEXT DEFAULT 'general',
                importance   REAL DEFAULT 0.5,
                access_count INTEGER DEFAULT 0,
                last_accessed DATE,
                tags         TEXT,       -- JSON array
                source       TEXT DEFAULT 'conversation'
            )
        """)
        cursor.execute("CREATE INDEX IF NOT EXISTS idx_user ON memories(user_id)")
        cursor.execute("CREATE INDEX IF NOT EXISTS idx_session ON memories(session_id)")

        # ── NEW: Persistent rubric buffer ────────────────────────────────────
        # One row per (query_key, rubric). query_key is a stable hash of the query.
        # These are generated ONCE from initial search and never deleted.
        cursor.execute("""
            CREATE TABLE IF NOT EXISTS rubric_buffer_persistent (
                id           TEXT PRIMARY KEY,   -- UUID
                query_key    TEXT NOT NULL,       -- hash of query string
                query_text   TEXT,               -- original query (for debugging)
                rubric_text  TEXT NOT NULL,       -- the criterion itself
                weight       REAL DEFAULT 1.0,   -- positive or negative
                rubric_type  TEXT DEFAULT 'positive',  -- 'positive' or 'negative'
                created_at   DATETIME DEFAULT CURRENT_TIMESTAMP
            )
        """)
        cursor.execute(
            "CREATE INDEX IF NOT EXISTS idx_persist_qk "
            "ON rubric_buffer_persistent(query_key)"
        )

        # ── NEW: Active (evolving) rubric buffer ─────────────────────────────
        # Generated at each retrieval cycle by contrasting used vs. unused memories.
        # Pruned by variance — rubrics that stop discriminating are deleted.
        cursor.execute("""
            CREATE TABLE IF NOT EXISTS rubric_buffer_active (
                id               TEXT PRIMARY KEY,
                query_key        TEXT,          -- NULL means session-wide rubric
                session_id       TEXT,          -- session scope
                rubric_text      TEXT NOT NULL,
                weight           REAL DEFAULT 1.0,
                rubric_type      TEXT DEFAULT 'positive',
                step_created     INTEGER,       -- training/session step when created
                last_variance    REAL,          -- most recent std across retrievals
                usage_count      INTEGER DEFAULT 0,
                created_at       DATETIME DEFAULT CURRENT_TIMESTAMP,
                last_updated     DATETIME DEFAULT CURRENT_TIMESTAMP
            )
        """)
        cursor.execute(
            "CREATE INDEX IF NOT EXISTS idx_active_qk "
            "ON rubric_buffer_active(query_key)"
        )
        cursor.execute(
            "CREATE INDEX IF NOT EXISTS idx_active_sess "
            "ON rubric_buffer_active(session_id)"
        )

        self.conn.commit()

    # ── Memory CRUD ──────────────────────────────────────────────────────────

    def add_memory(
        self,
        doc_id: str,
        text: str,
        user_id: Optional[str] = None,
        session_id: Optional[str] = None,
        memory_type: str = 'general',
        importance: float = 0.5,
        tags: Optional[list] = None,
        source: str = 'conversation'
    ):
        self.conn.execute("""
            INSERT OR REPLACE INTO memories
                (id, text, user_id, session_id, memory_type,
                 importance, tags, source)
            VALUES (?, ?, ?, ?, ?, ?, ?, ?)
        """, (
            doc_id, text, user_id, session_id, memory_type,
            importance, json.dumps(tags or []), source
        ))
        self.conn.commit()

    def get_memory(self, doc_id: str) -> Optional[dict]:
        row = self.conn.execute(
            "SELECT * FROM memories WHERE id = ?", (doc_id,)
        ).fetchone()
        if row:
            cols = [d[0] for d in self.conn.execute(
                "SELECT * FROM memories LIMIT 0"
            ).description]
            return dict(zip(cols, row))
        return None

    def batch_get_memories(self, doc_ids: list[str]) -> list[dict]:
        placeholders = ','.join(['?'] * len(doc_ids))
        rows = self.conn.execute(
            f"SELECT * FROM memories WHERE id IN ({placeholders})", doc_ids
        ).fetchall()
        cols = [d[0] for d in self.conn.execute(
            "SELECT * FROM memories LIMIT 0"
        ).description]
        return [dict(zip(cols, row)) for row in rows]

    def update_access(self, doc_id: str):
        self.conn.execute("""
            UPDATE memories
            SET access_count = access_count + 1,
                last_accessed = CURRENT_DATE
            WHERE id = ?
        """, (doc_id,))
        self.conn.commit()

    # ── Persistent Rubric Buffer CRUD ─────────────────────────────────────

    def add_persistent_rubric(
        self,
        rubric_id: str,
        query_key: str,
        query_text: str,
        rubric_text: str,
        weight: float = 1.0,
        rubric_type: str = 'positive'
    ):
        self.conn.execute("""
            INSERT OR IGNORE INTO rubric_buffer_persistent
                (id, query_key, query_text, rubric_text, weight, rubric_type)
            VALUES (?, ?, ?, ?, ?, ?)
        """, (rubric_id, query_key, query_text, rubric_text, weight, rubric_type))
        self.conn.commit()

    def get_persistent_rubrics(self, query_key: str) -> list[dict]:
        rows = self.conn.execute(
            "SELECT * FROM rubric_buffer_persistent WHERE query_key = ?",
            (query_key,)
        ).fetchall()
        cols = [d[0] for d in self.conn.execute(
            "SELECT * FROM rubric_buffer_persistent LIMIT 0"
        ).description]
        return [dict(zip(cols, row)) for row in rows]

    # ── Active (Evolving) Rubric Buffer CRUD ──────────────────────────────

    def add_active_rubric(
        self,
        rubric_id: str,
        rubric_text: str,
        weight: float = 1.0,
        rubric_type: str = 'positive',
        query_key: Optional[str] = None,
        session_id: Optional[str] = None,
        step_created: int = 0
    ):
        self.conn.execute("""
            INSERT INTO rubric_buffer_active
                (id, query_key, session_id, rubric_text, weight,
                 rubric_type, step_created)
            VALUES (?, ?, ?, ?, ?, ?, ?)
        """, (
            rubric_id, query_key, session_id, rubric_text,
            weight, rubric_type, step_created
        ))
        self.conn.commit()

    def get_active_rubrics(
        self,
        query_key: Optional[str] = None,
        session_id: Optional[str] = None
    ) -> list[dict]:
        """Retrieve active rubrics by query key and/or session ID."""
        if query_key and session_id:
            rows = self.conn.execute(
                "SELECT * FROM rubric_buffer_active "
                "WHERE query_key = ? OR session_id = ?",
                (query_key, session_id)
            ).fetchall()
        elif query_key:
            rows = self.conn.execute(
                "SELECT * FROM rubric_buffer_active WHERE query_key = ?",
                (query_key,)
            ).fetchall()
        elif session_id:
            rows = self.conn.execute(
                "SELECT * FROM rubric_buffer_active WHERE session_id = ?",
                (session_id,)
            ).fetchall()
        else:
            rows = []

        cols = [d[0] for d in self.conn.execute(
            "SELECT * FROM rubric_buffer_active LIMIT 0"
        ).description]
        return [dict(zip(cols, row)) for row in rows]

    def update_active_rubric_variance(self, rubric_id: str, variance: float):
        self.conn.execute("""
            UPDATE rubric_buffer_active
            SET last_variance = ?,
                usage_count = usage_count + 1,
                last_updated = CURRENT_TIMESTAMP
            WHERE id = ?
        """, (variance, rubric_id))
        self.conn.commit()

    def delete_active_rubric(self, rubric_id: str):
        self.conn.execute(
            "DELETE FROM rubric_buffer_active WHERE id = ?",
            (rubric_id,)
        )
        self.conn.commit()

    def prune_active_rubrics(
        self,
        query_key: Optional[str],
        session_id: Optional[str],
        k_max: int = 10
    ):
        """
        Variance-based pruning (RLER §3.2):
        1. Delete rubrics with last_variance = 0 (non-discriminative)
        2. Keep only top k_max by last_variance descending
        """
        # Step 1: Delete zero-variance rubrics
        if query_key:
            self.conn.execute("""
                DELETE FROM rubric_buffer_active
                WHERE query_key = ?
                  AND last_variance IS NOT NULL
                  AND last_variance = 0.0
            """, (query_key,))
        if session_id:
            self.conn.execute("""
                DELETE FROM rubric_buffer_active
                WHERE session_id = ?
                  AND last_variance IS NOT NULL
                  AND last_variance = 0.0
            """, (session_id,))

        # Step 2: Keep only top K_max by variance
        # Get all IDs sorted by variance desc
        rows = self.conn.execute("""
            SELECT id FROM rubric_buffer_active
            WHERE (query_key = ? OR session_id = ?)
            ORDER BY COALESCE(last_variance, 0) DESC
        """, (query_key or '', session_id or '')).fetchall()

        all_ids = [row[0] for row in rows]
        ids_to_delete = all_ids[k_max:]   # Keep top k_max, delete the rest

        if ids_to_delete:
            placeholders = ','.join(['?'] * len(ids_to_delete))
            self.conn.execute(
                f"DELETE FROM rubric_buffer_active WHERE id IN ({placeholders})",
                ids_to_delete
            )

        self.conn.commit()

6. Phase 3: Search & Retrieval

Phase 3 is the KNN retrieval layer — it is not where rubric scoring happens. This layer is responsible for producing a set of candidate memories efficiently. The rubric layer (Phase 4) then re-ranks these candidates. This separation is intentional: KNN is fast and approximate; rubric scoring is slower but semantically precise. Over-retrieve with KNN (e.g., top-50), then re-rank down to top-k with rubrics.

Practice 11: Basic Search Implementation

class DenseSearch:
    """
    KNN retrieval layer. Returns raw candidates with embedding scores.
    Does NOT apply rubric scoring — that happens in DenseMemory.
    """

    def __init__(
        self,
        encoder: 'DenseEncoder',
        vector_index: 'DenseVectorIndex',
        metadata_store: 'DenseMetadataStore'
    ):
        self.encoder = encoder
        self.vector_index = vector_index
        self.metadata_store = metadata_store

    def search_candidates(
        self,
        query: str,
        candidate_k: int = 50,   # Over-retrieve for rubric re-ranking
        user_id: Optional[str] = None,
        filters: Optional[dict] = None
    ) -> list[dict]:
        """
        Stage 1 of a two-stage retrieval:
          1. KNN over FAISS → candidate_k raw candidates
          2. (Caller applies rubric re-ranking to get final top-k)

        Returns list of dicts with keys:
          {id, text, embedding_score, metadata}
        """
        # Encode query
        query_vec = self.encoder.encode(query)   # (1, D)

        # KNN search
        raw_results = self.vector_index.search(query_vec, k=candidate_k)

        # Hydrate with metadata + apply optional filters
        candidates = []
        for result in raw_results:
            meta = self.metadata_store.get_memory(result['id'])
            if meta is None:
                continue

            # Apply user filter
            if user_id and meta.get('user_id') != user_id:
                continue

            # Apply custom filters
            if filters and not self._matches_filters(meta, filters):
                continue

            candidates.append({
                'id': result['id'],
                'text': meta['text'],
                'embedding_score': result['embedding_score'],
                'metadata': meta
            })

            self.metadata_store.update_access(result['id'])

        return candidates

    def _matches_filters(self, meta: dict, filters: dict) -> bool:
        for key, value in filters.items():
            if isinstance(value, list):
                if meta.get(key) not in value:
                    return False
            else:
                if meta.get(key) != value:
                    return False
        return True

def batch_search_candidates(
    self,
    queries: list[str],
    candidate_k: int = 50
) -> dict[int, list[dict]]:
    """Encode all queries at once, then batch-search FAISS."""
    query_vecs = self.encoder.encode(queries).astype('float32')  # (Q, D)

    all_scores, all_indices = self.vector_index.index.search(
        query_vecs, candidate_k

    for i, query in enumerate(queries):

            {

                'embedding_score': float(score)
            }
            for score, idx in zip(all_scores[i], all_indices[i])
            if idx >= 0
        ]
    return results

This is the new phase. Three components: RubricJudge, RubricGenerator, and RubricBuffer. Each maps directly to a component in RLER's training architecture, adapted for retrieval rather than policy training.

Component A: RubricJudge

import hashlib
import json
import diskcache

class RubricJudge:
    """
    JUDGE(r_k, m): Scores a retrieved memory m against rubric criterion r_k.
    Returns {0.0, 0.5, 1.0}.

    Critical design choice: results are CACHED.
    A memory's content doesn't change, so JUDGE(r_k, m) is deterministic.
    Caching eliminates redundant API calls when the same memory appears
    across multiple retrieval cycles.
    """

    def __init__(
        self,
        llm_client,          # OpenAI or Anthropic client
        model: str = 'gpt-4.1-mini',
        cache_dir: str = '.rubric_judge_cache'
    ):
        self.llm = llm_client
        self.model = model
        self.cache = diskcache.Cache(cache_dir)

    def score(
        self,
        rubric_text: str,
        memory_text: str,
        query_text: str
    ) -> float:
        """
        Score how well memory_text satisfies rubric_text given query_text.

        Cache key: hash(rubric_text + memory_text)
        Note: query_text is excluded from cache key because the rubric
        already encodes query-specific expectations. The same memory
        satisfies or doesn't satisfy a rubric regardless of how it
        was queried — the rubric is the query-aware component.
        """
        cache_key = hashlib.md5(
            f"{rubric_text}|||{memory_text}".encode()
        ).hexdigest()

        if cache_key in self.cache:
            return self.cache[cache_key]

        prompt = self._build_judge_prompt(rubric_text, memory_text, query_text)

        response = self.llm.chat.completions.create(
            model=self.model,
            messages=[{"role": "user", "content": prompt}],
            temperature=0.0,   # Deterministic judging
            response_format={"type": "json_object"}
        )

        raw = json.loads(response.choices[0].message.content)
        # Paper uses 0-2 scale internally, divide by 2 → {0.0, 0.5, 1.0}
        score = float(raw.get('score', 0)) / 2.0
        score = max(0.0, min(1.0, score))  # Clamp to [0, 1]

        self.cache[cache_key] = score
        return score

    def score_batch(
        self,
        rubric_text: str,
        memories: list[dict],
        query_text: str
    ) -> list[float]:
        """Score multiple memories against the same rubric."""
        return [
            self.score(rubric_text, m['text'], query_text)
            for m in memories
        ]

    def _build_judge_prompt(
        self,
        rubric_text: str,
        memory_text: str,
        query_text: str
    ) -> str:
        return f"""You are evaluating whether a retrieved memory satisfies a quality criterion.

Query context: {query_text}

Retrieved memory: {memory_text}

Criterion: {rubric_text}

Score how well the memory satisfies this criterion.
Return JSON: {{"score": X}} where X is:
- 0  = Does not satisfy the criterion at all
- 1  = Partially satisfies the criterion
- 2  = Fully satisfies the criterion

Only return the JSON object, nothing else."""

Component B: RubricGenerator

class RubricGenerator:
    """
    G_rubric: Generates new rubric criteria by contrasting used vs. unused
    memories from a retrieval cycle.

    This is the "evolving" in Evolving Rubrics.

    Mirrors RLER §3.2: "positive rubrics capture strengths or new relevant
    knowledge; negative rubrics summarize common undesirable behaviors."

    In the memory context:
    - Positive: What property made USED memories actually useful?
    - Negative: What property made UNUSED memories a waste of retrieval budget?
    """

    def __init__(
        self,
        llm_client,
        model: str = 'gpt-4.1',   # Stronger model for generation
        max_rubrics_per_cycle: int = 3
    ):
        self.llm = llm_client
        self.model = model
        self.max_rubrics = max_rubrics_per_cycle

    def generate_initial_rubrics(
        self,
        query_text: str,
        sample_memories: list[dict]
    ) -> list[dict]:
        """
        Called ONCE per query before the first retrieval cycle.
        Generates persistent search-grounded rubrics.

        Unlike RLER which uses web search for grounding, here we use a
        sample of existing memories to generate concrete, assertive criteria.
        This is the 'Initial Search-based Rubrics' from the paper.
        """
        memory_samples = "\n".join([
            f"Memory {i+1}: {m['text']}"
            for i, m in enumerate(sample_memories[:10])
        ])

        prompt = f"""You are designing retrieval quality criteria for a memory system.

Query: {query_text}

Sample memories available in the system:
{memory_samples}

Generate {self.max_rubrics} specific, assertive criteria that a HIGHLY RELEVANT
retrieved memory should satisfy for this query.

Requirements:
- Be CONCRETE: "The memory mentions the user's preference for X" not "The memory is relevant"
- Be TESTABLE: Another evaluator should reach the same pass/fail decision
- Be SPECIFIC to this query, not generic

Return JSON:
{{
    "positive_rubrics": [
        {{"text": "...", "weight": 1.0}},
        ...
    ]
}}"""

        response = self.llm.chat.completions.create(
            model=self.model,
            messages=[{"role": "user", "content": prompt}],
            temperature=0.3,
            response_format={"type": "json_object"}
        )

        raw = json.loads(response.choices[0].message.content)
        return raw.get('positive_rubrics', [])

    def generate_evolving_rubrics(
        self,
        query_text: str,
        used_memories: list[dict],       # Memories the agent cited/used
        unused_memories: list[dict],     # Memories retrieved but ignored
        existing_rubrics: list[dict],    # Current buffer (to avoid duplicates)
        step: int = 0
    ) -> list[dict]:
        """
        Called after each retrieval cycle where there is a contrast between
        used and unused memories.

        This is the core RLER evolving rubric generation step, applied to
        memory retrieval instead of LM rollouts.

        If len(used_memories) == 0 or len(unused_memories) == 0:
          No contrast available — return empty list. Do not generate rubrics
          from a single group, as they would have no discriminative power.
        """
        if not used_memories or not unused_memories:
            return []

        used_texts = "\n".join([
            f"USED {i+1}: {m['text']}"
            for i, m in enumerate(used_memories[:5])
        ])
        unused_texts = "\n".join([
            f"UNUSED {i+1}: {m['text']}"
            for i, m in enumerate(unused_memories[:5])
        ])
        existing_rubric_texts = "\n".join([
            f"- {r['rubric_text']}"
            for r in existing_rubrics[:15]
        ])

        prompt = f"""You are analyzing a memory retrieval session to generate discriminative criteria.

Query: {query_text}

Memories that were USED (cited, built upon, or referenced in the agent's response):
{used_texts}

Memories that were retrieved but NOT USED (ignored by the agent):
{unused_texts}

Existing criteria (DO NOT duplicate these):
{existing_rubric_texts}

Task: Identify NEW criteria that DISCRIMINATE between used and unused memories.
- Positive criteria: What property do USED memories have that unused ones lack?
- Negative criteria: What failure mode appears in UNUSED memories?

Requirements:
- Each criterion must be testable against a single memory in isolation
- Be ASSERTIVE: state exactly what should be present ("mentions X") not vague ("is relevant")
- Generate ONLY criteria that would score DIFFERENTLY across the shown memories
- If no new discriminating criteria exist beyond what's already listed, return empty lists

Return JSON (max {self.max_rubrics} total):
{{
    "positive_rubrics": [{{"text": "...", "weight": 1.0}}],
    "negative_rubrics": [{{"text": "...", "weight": -0.5}}]
}}"""

        response = self.llm.chat.completions.create(
            model=self.model,
            messages=[{"role": "user", "content": prompt}],
            temperature=0.3,
            response_format={"type": "json_object"}
        )

        raw = json.loads(response.choices[0].message.content)
        positives = raw.get('positive_rubrics', [])
        negatives = raw.get('negative_rubrics', [])

        # Tag type for storage
        for r in positives:
            r['rubric_type'] = 'positive'
        for r in negatives:
            r['rubric_type'] = 'negative'

        return positives + negatives

Component C: RubricBuffer

import uuid
import numpy as np
from typing import Optional

class RubricBuffer:
    """
    Two-compartment rubric buffer for a query/session.

    Compartment 1 — Persistent (R^persist):
      Generated once from initial query analysis.
      Maps to your 8-factor archetype-weighted utility system.
      Never deleted.

    Compartment 2 — Active/Evolving (R^active):
      Generated at each retrieval cycle by contrasting used vs. unused.
      Subject to variance-based pruning (K_max retention).
      Retired when std=0 (rubric stops discriminating).

    The variance filter is the core mechanism that keeps the buffer healthy:
    a rubric that ALL memories satisfy (or that NO memories satisfy) has
    std=0 and provides zero discriminative signal. It is automatically retired.
    """

    def __init__(
        self,
        metadata_store: 'DenseMetadataStore',
        rubric_judge: 'RubricJudge',
        rubric_generator: 'RubricGenerator',
        query_key: str,
        query_text: str,
        session_id: Optional[str] = None,
        k_max: int = 10,                # Max active rubrics retained
        archetype_weights: Optional[dict] = None   # Your 8-factor weights
    ):
        self.store = metadata_store
        self.judge = rubric_judge
        self.generator = rubric_generator
        self.query_key = query_key
        self.query_text = query_text
        self.session_id = session_id
        self.k_max = k_max
        self.step = 0

        # Bootstrap archetype-based persistent rubrics from your 8-factor system
        if archetype_weights:
            self._init_archetype_rubrics(archetype_weights)

    def _init_archetype_rubrics(self, archetype_weights: dict):
        """
        Convert your existing 8-factor utility scoring system into
        persistent rubric criteria.

        The 8 factors (Relevance, Authority, Recency, Diversity,
        Procedural Fit, Task Fit, Contradiction, Length) each become
        a rubric criterion with the archetype weight as the rubric weight.
        """
        factor_to_rubric = {
            'relevance':    "The memory directly addresses or provides context for the query topic",
            'authority':    "The memory comes from an authoritative, verified source or explicit user statement",
            'recency':      "The memory reflects recent context or has been recently confirmed",
            'diversity':    "The memory provides a perspective not already covered by other retrieved memories",
            'procedural':   "The memory contains procedural, how-to, or instructional information relevant to the task",
            'task_fit':     "The memory aligns with the specific task type being performed (research, coding, QA, etc.)",
            'contradiction':"The memory does NOT contradict other high-confidence memories in the session",
            'length':       "The memory has appropriate detail density — neither too sparse nor too verbose for the query"
        }

        for factor, rubric_text in factor_to_rubric.items():
            weight = archetype_weights.get(factor, 1.0)
            if abs(weight) > 0.01:    # Skip factors with near-zero weight
                rubric_id = str(uuid.uuid4())
                self.store.add_persistent_rubric(
                    rubric_id=rubric_id,
                    query_key=self.query_key,
                    query_text=self.query_text,
                    rubric_text=rubric_text,
                    weight=weight,
                    rubric_type='positive' if weight > 0 else 'negative'
                )

    def initialize_search_rubrics(self, sample_memories: list[dict]):
        """
        Generate initial search-grounded rubrics from available memories.
        Called once before the first retrieval cycle.
        """
        rubrics = self.generator.generate_initial_rubrics(
            self.query_text, sample_memories
        )
        for r in rubrics:
            rubric_id = str(uuid.uuid4())
            self.store.add_persistent_rubric(
                rubric_id=rubric_id,
                query_key=self.query_key,
                query_text=self.query_text,
                rubric_text=r['text'],
                weight=r.get('weight', 1.0),
                rubric_type='positive'
            )

    def compute_rubric_score(
        self,
        memory: dict,
        candidates: Optional[list[dict]] = None
    ) -> float:
        """
        S(q, m) = sum(w_k * JUDGE(r_k, m)) / sum(w_k for positive w_k)

        This is equation (1) from the RLER paper, applied to memory retrieval.
        """
        all_rubrics = (
            self.store.get_persistent_rubrics(self.query_key)
            + self.store.get_active_rubrics(
                query_key=self.query_key,
                session_id=self.session_id
            )
        )

        if not all_rubrics:
            return 0.5   # No rubrics yet — neutral score

        weighted_sum = 0.0
        positive_weight_sum = 0.0

        for rubric in all_rubrics:
            judge_score = self.judge.score(
                rubric_text=rubric['rubric_text'],
                memory_text=memory['text'],
                query_text=self.query_text
            )
            w = rubric['weight']
            weighted_sum += w * judge_score
            if w > 0:
                positive_weight_sum += w

        if positive_weight_sum == 0:
            return 0.0

        return weighted_sum / positive_weight_sum

    def evolve(
        self,
        retrieved_candidates: list[dict],
        used_memory_ids: set[str]
    ):
        """
        Core RLER evolving rubric step.

        Called after the agent uses retrieved memories.
        Contrasts used vs. unused memories to generate new rubrics.
        Updates the active rubric buffer with variance filtering.

        Parameters:
          retrieved_candidates: All memories returned by the search
          used_memory_ids: IDs of memories the agent actually cited/used
        """
        self.step += 1

        used   = [m for m in retrieved_candidates if m['id'] in used_memory_ids]
        unused = [m for m in retrieved_candidates if m['id'] not in used_memory_ids]

        if not used or not unused:
            return   # No contrast available

        # Step 1: Generate new rubrics by contrasting used vs. unused
        existing = (
            self.store.get_persistent_rubrics(self.query_key)
            + self.store.get_active_rubrics(
                query_key=self.query_key,
                session_id=self.session_id
            )
        )

        new_rubrics = self.generator.generate_evolving_rubrics(
            query_text=self.query_text,
            used_memories=used,
            unused_memories=unused,
            existing_rubrics=existing,
            step=self.step
        )

        # Step 2: Add new rubrics to active buffer
        for r in new_rubrics:
            rubric_id = str(uuid.uuid4())
            self.store.add_active_rubric(
                rubric_id=rubric_id,
                rubric_text=r['text'],
                weight=r.get('weight', 1.0),
                rubric_type=r.get('rubric_type', 'positive'),
                query_key=self.query_key,
                session_id=self.session_id,
                step_created=self.step
            )

        # Step 3: Compute variance for all active rubrics over this candidate set
        active_rubrics = self.store.get_active_rubrics(
            query_key=self.query_key,
            session_id=self.session_id
        )

        for rubric in active_rubrics:
            scores = self.judge.score_batch(
                rubric_text=rubric['rubric_text'],
                memories=retrieved_candidates,
                query_text=self.query_text
            )
            variance = float(np.std(scores))
            self.store.update_active_rubric_variance(rubric['id'], variance)

        # Step 4: Prune by variance — same rule as RLER Algorithm 1
        # Remove std=0 rubrics; keep top K_max by std descending
        self.store.prune_active_rubrics(
            query_key=self.query_key,
            session_id=self.session_id,
            k_max=self.k_max
        )

Rubric Re-ranking: Hybrid Score Computation

This function belongs in the search/memory layer and combines KNN scores with rubric scores:

def compute_hybrid_scores(
    candidates: list[dict],
    rubric_buffer: 'RubricBuffer',
    alpha: float = 0.50,   # Embedding similarity weight
    beta:  float = 0.35,   # Rubric score weight
    gamma: float = 0.15,   # Recency weight
) -> list[dict]:
    """
    Re-rank KNN candidates using rubric scores.

    The three-way hybrid mirrors a combined retrieval score:
      - alpha: semantic proximity (from FAISS)
      - beta:  rubric quality (from evolving rubric buffer)
      - gamma: temporal recency (from metadata)

    α + β + γ = 1.0
    """
    import datetime

    def recency_score(timestamp_str: Optional[str]) -> float:
        """Exponential decay: very recent → 1.0, 1-year-old → ~0.37"""
        if not timestamp_str:
            return 0.5
        try:
            ts = datetime.datetime.fromisoformat(timestamp_str)
            age_days = (datetime.datetime.now() - ts).days
            return float(np.exp(-age_days / 365))   # λ = 1/365
        except Exception:
            return 0.5

    # Normalize embedding scores from [-1,1] to [0,1]
    emb_scores = np.array([c['embedding_score'] for c in candidates])
    emb_norm = (emb_scores + 1) / 2   # Maps [-1,1] → [0,1]

    scored = []
    for i, candidate in enumerate(candidates):
        rubric_score = rubric_buffer.compute_rubric_score(candidate)
        recency      = recency_score(
            candidate.get('metadata', {}).get('timestamp')
        )

        final_score = (
            alpha * emb_norm[i]
            + beta  * rubric_score
            + gamma * recency
        )

        scored.append({
            **candidate,
            'rubric_score':    rubric_score,
            'recency_score':   recency,
            'embedding_score_norm': float(emb_norm[i]),
            'final_score':     float(final_score)
        })

    # Re-rank by final hybrid score
    scored.sort(key=lambda x: x['final_score'], reverse=True)
    return scored

8. Phase 5: Integration — DenseMemory

The unified memory interface that wires all layers together. The rubric evolution loop is triggered automatically after each search call when observe_usage() is called by the agent.

import os
import uuid
import hashlib
from typing import Optional

class DenseMemory:
    """
    Unified dense memory system with evolving rubric re-ranking.

    Usage pattern:
      1. memory.add(text, user_id, session_id)
      2. candidates = memory.search(query, user_id, session_id, k=10)
      3. agent uses some of the candidates...
      4. memory.observe_usage(query, candidates, used_ids, session_id)
         → triggers rubric evolution for future searches

    The observe_usage() call is what makes rubrics "evolve."
    Without it, the system behaves as pure KNN retrieval with static
    archetype-weighted rubrics. With it, rubrics co-evolve with
    the agent's actual behavior — exactly mirroring RLER.
    """

    def __init__(
        self,
        encoder_model: str = 'BAAI/bge-m3',
        db_path: str = 'memory.db',
        index_dir: str = 'memory_index/',
        llm_client = None,           # OpenAI/Anthropic client for rubrics
        judge_model: str = 'gpt-4.1-mini',
        generator_model: str = 'gpt-4.1',
        archetype_weights: Optional[dict] = None,
        k_max_rubrics: int = 10,
        device: str = 'cpu'
    ):
        # ── Core layers ──────────────────────────────────────────────────────
        self.encoder = DenseEncoder(encoder_model, device=device)
        self.metadata_store = DenseMetadataStore(db_path)
        self.vector_index = DenseVectorIndex(
            dimension=self.encoder.dimension,
            index_type='flat'
        )
        self.search_engine = DenseSearch(
            self.encoder, self.vector_index, self.metadata_store
        )

        # ── Rubric layer ─────────────────────────────────────────────────────
        self.llm = llm_client
        self.rubric_judge = RubricJudge(llm_client, model=judge_model) if llm_client else None
        self.rubric_generator = RubricGenerator(llm_client, model=generator_model) if llm_client else None
        self.archetype_weights = archetype_weights or {
            'relevance':    1.0,
            'recency':      0.8,
            'authority':    0.6,
            'diversity':    0.5,
            'task_fit':     0.7,
            'procedural':   0.4,
            'contradiction': -1.0,  # Penalty
            'length':       0.3
        }
        self.k_max_rubrics = k_max_rubrics

        # ── Active rubric buffers: one per query_key ──────────────────────────
        self._rubric_buffers: dict[str, RubricBuffer] = {}

        # ── State ────────────────────────────────────────────────────────────
        self.index_dir = index_dir
        self._load_index_if_exists()

    # ── Memory Management ───────────────────────────────────────────────────

    def add(
        self,
        text: str,
        user_id: Optional[str] = None,
        session_id: Optional[str] = None,
        memory_type: str = 'general',
        importance: float = 0.5,
        tags: Optional[list] = None
    ) -> str:
        """Add a memory. Returns the new memory's ID."""
        doc_id = str(uuid.uuid4())

        # Store metadata
        self.metadata_store.add_memory(
            doc_id=doc_id,
            text=text,
            user_id=user_id,
            session_id=session_id,
            memory_type=memory_type,
            importance=importance,
            tags=tags
        )

        # Encode and add to FAISS
        vector = self.encoder.encode(text)   # (1, D)
        self.vector_index.add(vector, [doc_id])

        return doc_id

    def delete(self, doc_id: str):
        """
        Logical deletion — marks memory as deleted in metadata.
        FAISS index will be cleaned up on next rebuild().
        """
        self.metadata_store.conn.execute(
            "UPDATE memories SET memory_type = 'deleted' WHERE id = ?",
            (doc_id,)
        )
        self.metadata_store.conn.commit()

    def rebuild(self):
        """
        Rebuild FAISS index from all non-deleted memories in SQLite.
        Call after bulk deletions or on a scheduled cadence.
        """
        rows = self.metadata_store.conn.execute(
            "SELECT id, text FROM memories WHERE memory_type != 'deleted'"
        ).fetchall()

        if not rows:
            return

        ids   = [r[0] for r in rows]
        texts = [r[1] for r in rows]

        vectors = self.encoder.encode(texts, batch_size=64)
        n = len(ids)
        index_type = 'hnsw' if n > 10_000 else 'flat'

        self.vector_index = DenseVectorIndex(
            dimension=self.encoder.dimension,
            index_type=index_type
        )
        self.vector_index.add(vectors, ids)
        self._save_index()

    # ── Search ────────────────────────────────────────────────────────────

    def search(
        self,
        query: str,
        user_id: Optional[str] = None,
        session_id: Optional[str] = None,
        k: int = 10,
        candidate_multiplier: int = 5,   # Over-retrieve factor for rubric re-ranking
        use_rubrics: bool = True,
        filters: Optional[dict] = None
    ) -> list[dict]:
        """
        Two-stage search:
          Stage 1: KNN via FAISS — retrieve k * candidate_multiplier candidates
          Stage 2: Rubric re-ranking — score candidates, return top-k

        If use_rubrics=False or no LLM client configured:
          Falls back to pure KNN with metadata-boosted scoring.
        """
        candidate_k = k * candidate_multiplier

        # Stage 1: KNN candidates
        candidates = self.search_engine.search_candidates(
            query=query,
            candidate_k=candidate_k,
            user_id=user_id,
            filters=filters
        )

        if not candidates:
            return []

        # Stage 2: Rubric re-ranking (if rubrics are enabled)
        if use_rubrics and self.rubric_judge and self.rubric_generator:
            buffer = self._get_or_create_rubric_buffer(
                query, session_id, candidates
            )
            candidates = compute_hybrid_scores(
                candidates=candidates,
                rubric_buffer=buffer,
                alpha=0.50,
                beta=0.35,
                gamma=0.15
            )
        else:
            # Fallback: simple embedding + recency hybrid (no rubric component)
            for c in candidates:
                c['final_score'] = c['embedding_score']
            candidates.sort(key=lambda x: x['final_score'], reverse=True)

        # Return top-k
        return candidates[:k]

    def observe_usage(
        self,
        query: str,
        retrieved_candidates: list[dict],
        used_memory_ids: set[str],
        session_id: Optional[str] = None
    ):
        """
        Post-search callback: triggers rubric evolution.

        Call this after the agent has consumed the search results and you
        know which memories were actually used (cited, referenced, built upon).

        This is the RLER 'contrasting rollouts → generate new rubrics → update
        buffer' step, applied to memory retrieval.

        Parameters:
          retrieved_candidates: The list returned by search()
          used_memory_ids: Set of memory IDs that the agent used
        """
        if not self.rubric_generator:
            return   # No LLM client — rubric evolution disabled

        query_key = self._query_key(query)
        buffer = self._rubric_buffers.get(query_key)

        if buffer is None:
            return   # No buffer for this query yet

        buffer.evolve(
            retrieved_candidates=retrieved_candidates,
            used_memory_ids=used_memory_ids
        )

    # ── Internal helpers ──────────────────────────────────────────────────

    def _query_key(self, query: str) -> str:
        """Stable hash of query string for rubric buffer lookup."""
        return hashlib.md5(query.encode()).hexdigest()

    def _get_or_create_rubric_buffer(
        self,
        query: str,
        session_id: Optional[str],
        sample_candidates: list[dict]
    ) -> 'RubricBuffer':
        """
        Retrieve existing rubric buffer for this query key, or create a new one.

        On creation:
          1. Bootstrap archetype-weighted persistent rubrics
          2. Generate initial search-grounded rubrics from sample memories
        """
        query_key = self._query_key(query)

        if query_key not in self._rubric_buffers:
            buffer = RubricBuffer(
                metadata_store=self.metadata_store,
                rubric_judge=self.rubric_judge,
                rubric_generator=self.rubric_generator,
                query_key=query_key,
                query_text=query,
                session_id=session_id,
                k_max=self.k_max_rubrics,
                archetype_weights=self.archetype_weights
            )
            # Initialize with search-grounded rubrics from candidate sample
            buffer.initialize_search_rubrics(sample_candidates[:10])
            self._rubric_buffers[query_key] = buffer

        return self._rubric_buffers[query_key]

    def _save_index(self):
        os.makedirs(self.index_dir, exist_ok=True)
        self.vector_index.save(self.index_dir)

    def _load_index_if_exists(self):
        if os.path.exists(f'{self.index_dir}/index.faiss'):
            self.vector_index.load(self.index_dir)

10. Key Takeaways

Retrieval Layer

  1. Over-retrieve with KNN: Default to k * 5 candidates from FAISS — rubric re-ranking needs headroom
  2. Shape & dtype: Query vector must be (1, D) and float32 before FAISS search
  3. Two-stage pipeline: KNN gives you candidates fast; rubrics give you the right ones precisely
  4. Normalize always: L2-normalize all vectors so IndexFlatIP equals cosine similarity
  5. Start flat, upgrade later: IndexFlatIP for dev/small scale; switch to HNSW at >10k memories

Encoding Layer

  1. Single encoder for queries and memories: Same pooling, same normalization — consistency matters
  2. Mean pool for sentence-transformers models: CLS pool only for BERT-style classification models
  3. Batch size 32–64: Balance GPU utilization vs. memory footprint
  4. Model choice matters: BAAI/bge-m3 for quality; all-MiniLM-L6-v2 for speed

Storage Layer

  1. FAISS for vectors only: All metadata, rubric buffers, and access stats live in SQLite
  2. Three SQLite tables: memories, rubric_buffer_persistent, rubric_buffer_active
  3. Logical deletion: Mark as deleted in metadata; clean up FAISS on scheduled rebuild()
  4. IndexIDMap for frequent deletes: Adds overhead but avoids full rebuilds

Rubric System

  1. Persistent rubrics never change: Bootstrap from archetype weights; they are your stable priors
  2. Active rubrics are transient: Generated from retrieval contrasts; pruned when they stop discriminating
  3. The variance filter is the key mechanism: std(r_k) = 0 means the rubric scores all candidates the same — it provides zero gradient signal and should be retired immediately
  4. Cache JUDGE results aggressively: JUDGE(r_k, memory_m) is deterministic — memory content doesn't change. Disk-cache every judge call to avoid redundant LLM API costs
  5. Use a cheaper model for judging: Judge is called K × N times per search cycle. Use gpt-4.1-mini or claude-haiku, not the full model
  6. Evolving rubrics require contrast: If every retrieved memory was used, or none was used, there's no signal. observe_usage() is a no-op in these edge cases
  7. observe_usage() is the RLER step: Without it, the system is pure KNN + static archetype rubrics. The evolution only happens when you close the feedback loop by reporting what was actually used

Architecture

  1. Rubric buffer is per query_key, not per search call: The same query benefits from rubric history across multiple sessions. This is where "evolving" truly accumulates
  2. Session-wide active rubrics: Rubrics with session_id but no query_key apply broadly to all retrievals in a session — useful for capturing session-level context shifts
  3. α + β + γ = 1.0: Keep hybrid weights normalized; this makes the final score directly comparable across queries and sessions
  4. Train-test mismatch warning (from RLER paper): The LLM judge's biases become your system's retrieval biases over time. Monitor judge consistency if you switch models
