Hippocampal Neuroscience — A Deep Reference

1. The Macro Anatomy — Locating the System

The hippocampus is a curved, bilateral structure nested inside the medial temporal lobe of each cerebral hemisphere. Its name comes from the Greek for "seahorse" — the cross-section resembles one. It is part of the limbic system and is the structure most tightly associated with episodic memory (memories of specific events in time and place) and spatial navigation.

The medial temporal lobe memory system

The hippocampus does not operate alone. It sits at the apex of a medial temporal lobe (MTL) hierarchy:

Neocortex (all sensory and association areas)
    ↓  (converging projections)
Perirhinal Cortex  ←→  Parahippocampal Cortex
    ↓                        ↓
Lateral Entorhinal Cortex   Medial Entorhinal Cortex
             ↓
        Hippocampus
           (DG → CA3 → CA1)
             ↓
        Back to Entorhinal Cortex
             ↓
        Back to Neocortex

This is a bidirectional hierarchy: sensory information flows in through the entorhinal cortex, gets processed through the hippocampal circuit, and flows back out to the cortex to update neocortical representations. The loop is not unidirectional — the hippocampus both reads from and writes to the cortex.

Hippocampal subfields (from medial to lateral in the curved structure)

Subfield Key cell type Primary role
CA4 / Hilus Mossy cells, interneurons Modulate DG activity; contribute to pattern separation support
Dentate Gyrus (DG) Granule cells (~1 million in humans) Pattern separation — make similar inputs orthogonal
CA3 Pyramidal cells with massive recurrent collaterals Pattern completion — reconstruct full memory from partial cue
CA1 Pyramidal cells (output layer) Comparator — detect mismatch between expectation and reality
Subiculum Pyramidal cells Output relay to entorhinal cortex, prefrontal cortex, and hypothalamus

2. The Trisynaptic Circuit — The Load-Bearing Loop

The classical hippocampal circuit involves three synaptic hops between the entorhinal cortex and CA1. This is called the trisynaptic pathway or trisynaptic loop:

Entorhinal Cortex Layer II (EC2)
      │  ←─── Perforant Path (PP)
      ▼
Dentate Gyrus (granule cells)
      │  ←─── Mossy Fiber Pathway (MF)
      ▼
CA3 (pyramidal cells)
      │  ←─── Schaffer Collaterals (SC)
      ▼
CA1 (pyramidal cells)
      │
      ▼
Subiculum → Entorhinal Cortex Layer V/VI → Back to neocortex

Why three synapses, not one? The layered architecture enforces computational separation. Each hop transforms the representation in a specific way:

  • Hop 1 (PP → DG): decorrelates similar inputs into distinct sparse codes.
  • Hop 2 (MF → CA3): uses those sparse codes to set up an autoassociative attractor network.
  • Hop 3 (SC → CA1): compares the reconstructed memory (from CA3) against current input (directly from EC layer III) and signals mismatches.

There is also a monosynaptic path from EC3 directly to CA1, bypassing DG and CA3 entirely. This direct route is thought to carry current sensory input ("what is happening right now"), while the trisynaptic path carries completed, reconstructed memory ("what was previously associated with this cue").

3. Layer-by-Layer: Entorhinal Cortex

What it is

The entorhinal cortex (EC) is the primary gateway between the hippocampus and the rest of the neocortex. It has two functional divisions:

Medial Entorhinal Cortex (MEC): Carries allocentric spatial information — where you are in abstract space. It contains grid cells, which fire in a remarkable hexagonal grid pattern tiling the entire environment, independent of specific landmarks. Grid cells encode the brain's internal metric for space and are the primary input for path integration (computing position from movement, without external cues).

Lateral Entorhinal Cortex (LEC): Carries object and landmark information — what is in the environment. Responds to specific sensory stimuli, objects, and contextual cues. Less grid-like, more item-centric.

Grid cells (MEC)

Grid cells, discovered by May-Britt Moser and Edvard Moser (Nobel Prize 2014), fire whenever an animal passes through vertices of an invisible hexagonal lattice. Different grid cells have different scales and orientations of their grids. The key properties:

  • Hexagonal periodicity — firing locations form a perfect triangular lattice.
  • Spatial scale gradient — dorsal EC has fine-grained small grids; ventral EC has coarse large grids. This gradient may allow the brain to represent space at multiple resolutions simultaneously.
  • Path integration — grid cells can maintain their spatial representation based purely on self-motion signals, even in the dark without landmarks.
  • Generalization to abstract spaces — human fMRI studies show grid-like signals (6-fold modulation of entorhinal activity) not just during navigation but during conceptual reasoning, suggesting grid codes may be a domain-general computation for structured cognition.

The two entorhinal input paths to the hippocampus

Path Origin Target Information type
Perforant Path EC layer II (stellate cells) DG granule cells and CA3 Initial, unprocessed sensory context
Temporo-ammonic Path EC layer III CA1 distal dendrites Current sensory input (for comparison)
Return projection CA1 / Subiculum EC layer V/VI Processed, completed hippocampal output

Theta oscillations in the EC

The EC is the main source of theta oscillations (4–10 Hz) to the hippocampus. During the encoding half of the theta cycle, EC input is strong, telling the hippocampus about the current situation. During the retrieval half, EC input weakens and CA3 recurrent activity drives retrieval of stored patterns. This theta-phase segregation of encoding vs retrieval is a fundamental mechanism preventing interference between what you're learning now and what you're recalling.

4. Layer-by-Layer: Dentate Gyrus (DG) — Pattern Separation

Core computation: Pattern Separation

Pattern separation is the process of transforming similar input representations into non-overlapping (orthogonal) output representations. It is the biological solution to the catastrophic interference problem: without it, learning new information that resembles old information would overwrite the old.

The DG achieves pattern separation through three mechanisms:

1. Sparse coding through inhibition

The DG contains approximately 1 million granule cells in the human brain, roughly 10× more than the number of EC input cells (~100,000 stellate cells). This expansion recoding — more output neurons than input neurons — allows the DG to spread representations across a much larger coding space. Crucially, only about 2–5% of granule cells are active at any given time (the rest are held silent by powerful inhibitory interneurons). Sparse codes mean that two similar inputs, when each maps to only 2–5% of a million neurons, are statistically almost guaranteed to activate non-overlapping populations. The sparse, distributed code produced by DG is the raw material for CA3 to work with.

2. Competitive inhibition between granule cells

Mossy cells in the hilus (CA4 region) and parvalbumin-positive basket cells enforce lateral inhibition among granule cells: when one granule cell fires, it suppresses its neighbors. This is a winner-takes-most dynamics that sharpens the separation between similar patterns.

3. Adult neurogenesis adds a continuous source of plastic neurons

The DG is one of the only brain regions in mammals (including humans) where new neurons continue to be born throughout adulthood. These new neurons, for several weeks after their birth, are hyperexcitable and highly plastic — they respond strongly to novelty and are modulated by theta oscillations. They enhance the DG's ability to distinguish between similar but distinct events, especially for fine-grained discrimination. As they mature, they become more like standard granule cells.

What "pattern separation" means computationally

Consider two memories that share 70% of their features (e.g., "Tuesday's meeting in room A" vs "Wednesday's meeting in room A"). The DG takes these 70%-overlapping EC representations and produces DG outputs that might share only 10–20% overlap. This prevents CA3 from wrongly completing "Wednesday's meeting" when you cue with "Tuesday's meeting."

The metric is population vector overlap — the proportion of neurons active in both representations. DG systematically reduces this overlap for similar inputs.

The DG as an error-correction module

Recent evidence from CA3 sequence recordings (Nature Communications, January 2025) suggests that DG input to CA3 may serve a temporal error-correction function: it fires to correct CA3 when its internally generated sequence drifts from the correct temporal order. This makes DG not just a one-shot pattern-separator at encoding time, but a continuous online corrector during sequence replay.

5. Layer-by-Layer: CA3 — Pattern Completion and Attractor Dynamics

Anatomy that defines the computation

CA3 has an extraordinary anatomical feature: massive recurrent collaterals. Each CA3 pyramidal cell sends axon branches to approximately 2,500–4,000 other CA3 cells within the same layer. This makes CA3 a densely connected autoassociative network — a network that connects its own outputs back to its own inputs.

The DG-to-CA3 mossy fiber projection is strong but sparse: each mossy fiber contacts only ~15 CA3 cells out of ~300,000. This "strong sparse input" is thought to serve as a forced pattern during encoding — the DG essentially forces CA3 into a specific firing pattern associated with the new input, which then gets stored in the CA3 recurrent synapses via Hebbian plasticity.

Core computation: Pattern Completion

Pattern completion is the reverse of pattern separation. Given a partial cue — a fragment of a previously stored memory — CA3's recurrent network uses its stored synaptic weights to reconstruct the full pattern that was associated with that fragment during encoding.

This works because:

  1. During encoding, cells that fired together in CA3 for a given experience had their mutual synapses strengthened (Hebbian LTP).
  2. During retrieval, a partial cue activates a small subset of the original pattern.
  3. The recurrent connections from these active cells then activate their learned partners.
  4. Activity propagates through the recurrent network until a stable, complete pattern is reached.

The complete, stable pattern is called an attractor — a state the network's dynamics settle into and remain in despite perturbations.

Attractor dynamics in detail

The CA3 network is formally an attractor network, specifically a Hopfield network variant. It stores memories as stable fixed-point attractors in a high-dimensional space defined by the N×N synaptic weight matrix of the recurrent connections.

Point attractors: A specific memory is encoded as a stable firing pattern (an attractor state). Even if you start with only 30% of the neurons that were active during encoding, the network dynamics will pull the system toward the full stored pattern.

Continuous attractors: For spatial memory and navigation, CA3 is believed to implement continuous attractor dynamics — instead of discrete fixed points, there is a continuous manifold of stable states corresponding to different positions in space. The animal's current position can "slide" smoothly along this manifold as they move, driven by grid cell inputs from MEC.

Capacity limit: A Hopfield network with N neurons can store roughly 0.14N memories before retrieval accuracy degrades. The DG's pattern separation is critical here: if similar memories were encoded as overlapping CA3 patterns, the attractor dynamics would fail (the network would land on a "blend" of two memories rather than one clean attractor). DG's sparse orthogonalization is what allows CA3's capacity to be used efficiently.

How similar inputs are handled:

When CA3 receives an input that matches one stored memory more than others, the attractor dynamics "pull" the network representation toward that stored attractor. If the input is genuinely ambiguous (similar to two memories), competition between the two attractors determines which one wins. The winner is the one whose attractor basin the current cue lies in — a function of both similarity and prior strengthening.

The double dissociation of DG-CA3 and direct EC-CA3 in encoding vs retrieval

A critical experimental finding: contralateral lesions of DG-CA3 impair encoding but not retrieval, while damage to the direct EC-CA3 path impairs retrieval but not encoding. This reveals:

  • DG-CA3 (via mossy fibers): Dominant during new encoding — the sparse, strong mossy fiber input forces a new pattern into CA3, creating a new attractor.
  • Direct EC input to CA3: Dominant during retrieval — the entorhinal cue weakly activates CA3, and the recurrent collaterals do the work of completing the stored pattern.

This is the theta-phase mechanism described earlier: mossy fiber-driven encoding in one theta half-cycle, recurrent-collateral-driven retrieval in the other.

6. Layer-by-Layer: CA1 — Comparator and Output Gateway

Two inputs, one job: comparison

CA1 receives two inputs on different dendritic compartments simultaneously:

Input Source Dendritic location Content
Schaffer Collaterals CA3 (via recurrent completion) Proximal dendrites (stratum radiatum) Reconstructed/completed memory
Temporo-ammonic Path EC layer III (direct) Distal dendrites (stratum lacunosum-moleculare) Current sensory input

CA1's comparator function is the computation that results from these two inputs being integrated in the same neuron:

  • If CA3 output matches EC3 input: familiar situation, expected outcome. CA1 fires moderately. Memory retrieval is confirmed.
  • If CA3 output mismatches EC3 input: something unexpected. CA1 generates a novelty/error signal. This mismatch triggers theta-burst activity, which drives attention, heightened encoding, and potential updating of CA3 representations.

This is the hippocampal version of predictive error signaling — the same computation that drives learning in reinforcement learning (prediction vs. outcome) is implemented here at the circuit level.

CA1 as the output gate

CA1 is the primary output layer of the hippocampus. Its axons project to:

  • Subiculum → which then projects to EC layer V/VI (feeding back to cortex), as well as to prefrontal cortex, hypothalamus, and amygdala.
  • EC directly (a subset of CA1 axons bypass the subiculum).

The CA1 output is the hippocampus's processed verdict on the current situation, delivered back to the neocortex.

Prospective and retrospective coding

CA1 neurons — specifically "place cells" in spatial tasks — have a striking property called journey-dependent firing: the same spatial location produces different CA1 firing patterns depending on where the animal just came from (retrospective coding) or where it is about to go (prospective coding).

At a maze choice point, CA1 cells sweep forward through the upcoming paths, mentally simulating possible trajectories before the animal physically moves. This "forward sweeping" during theta oscillations is a neural correlate of planning and imagination — the brain replaying possible futures to evaluate them.

The CA1 comparator as the contradiction detector

CA1 receives both reconstructed hippocampal activity and more direct cortical input. Comparing these streams may help distinguish recalled expectations from current input and signal novelty or mismatch.

7. How Information Actually Flows — The Full Signal Arc

Here is the complete signal flow for a single memory retrieval event, from sensory input to recalled memory:

Encoding (storing a new memory)

1. SENSORY EXPERIENCE (neocortex)
   → Visual cortex, auditory cortex, somatosensory cortex all active

2. CONVERGENCE at PERIRHINAL + PARAHIPPOCAMPAL CORTEX
   → Object identity (what) processed in perirhinal
   → Spatial context (where) processed in parahippocampal / postrhinal

3. ENTORHINAL CORTEX (EC) LAYER II
   → Integrates "what" + "where" into a combined representation
   → Grid cells (MEC) add a spatial coordinate
   → LEC adds object/context identity

4. PERFORANT PATH → DENTATE GYRUS
   → EC2 stellate cells project via the perforant path to DG granule cells
   → DG performs pattern separation: produces a sparse, orthogonalized code
   → Adult-born neurons (if present and relevant) add high plasticity

5. MOSSY FIBERS → CA3
   → Sparse but powerful synapses from DG granule cells onto CA3 pyramidal cells
   → Forces a specific CA3 firing pattern (the "teaching signal")
   → Hebbian plasticity strengthens CA3 recurrent connections between co-active cells
   → The memory is now "stored" as a distributed pattern in CA3 synaptic weights

6. SCHAFFER COLLATERALS → CA1
   → CA3 outputs via Schaffer collaterals to CA1 proximal dendrites
   → Simultaneously, EC3 sends direct input to CA1 distal dendrites
   → CA1 integrates both: confirms encoding, generates output

7. CA1 → SUBICULUM → EC LAYER V/VI → NEOCORTEX
   → Processed signal feeds back to neocortex
   → Neocortical representation is slightly updated

Retrieval (recalling a stored memory)

1. PARTIAL CUE (neocortex or internal state)
   → A fragment of a past experience becomes active

2. ENTORHINAL CORTEX LAYER II
   → Cue is translated into an EC representation (sparse but similar to encoding-time EC pattern)

3. PERFORANT PATH → CA3 (direct, bypassing DG partly)
   → Weak perforant path input provides a partial cue to CA3 recurrent network
   → DG-derived sparse code also arrives, helping disambiguate similar memories

4. CA3 RECURRENT COMPLETION
   → Partial pattern activates stored attractor
   → Recurrent collaterals propagate activity until stable attractor is reached
   → Full pattern reconstructed from partial cue

5. SCHAFFER COLLATERALS → CA1
   → Completed CA3 pattern arrives at CA1 proximal dendrites
   → Current sensory input arrives from EC3 at CA1 distal dendrites
   → CA1 performs comparator function: match → retrieval confirmed; mismatch → error signal

6. IF MATCH: CA1 → SUBICULUM → EC → NEOCORTEX
   → Completed memory reinstates neocortical pattern from encoding time
   → The subjective experience of "remembering"

7. IF MISMATCH: Theta burst firing
   → Hippocampus flags novelty/error
   → Increased attention, heightened encoding of the mismatch
   → Possible updating of CA3 attractor (reconsolidation)

8. Oscillatory Infrastructure — Theta, Gamma, and Sharp-Wave Ripples

Brain oscillations are not epiphenomenal. They are the timing infrastructure that organizes which neurons communicate with which, and when. Without understanding oscillations, the circuit behavior described above is incomplete.

Theta oscillations (4–10 Hz)

Theta is the dominant hippocampal rhythm during active exploration, navigation, and active recall. Generated primarily by the medial septum (via cholinergic and GABAergic projections to hippocampus) and modulated by EC input.

The encoding/retrieval theta-phase split (Hasselmo model): Within each ~125ms theta cycle:

  • First half (peak): EC3 → CA1 direct input is strong; CA3 → CA1 (Schaffer) is weak. Long-term potentiation (LTP) at CA3 synapses is high. → Encoding phase.
  • Second half (trough): EC3 → CA1 direct input weakens; CA3 → CA1 is strong. → Retrieval phase.

This elegant temporal alternation within every 125ms cycle prevents encoding and retrieval from interfering with each other — a form of time-division multiplexing at the neural circuit level.

Theta sequences: During theta, place cells don't just fire independently — they fire in sequences within each theta cycle that compress a future trajectory into a 125ms window. If a rat is at position P moving toward goal G, within a single theta cycle: cells representing positions between P and G fire in order, sweeping from current location to anticipated future location. This is the brain's mechanism for prospective coding and planning on a timescale too fast for deliberate thought.

Gamma oscillations (30–100 Hz)

Gamma oscillations are faster and local. There are two distinct gamma bands in the hippocampus:

Band Frequency Origin Function
Slow gamma (30–50 Hz) Generated locally in hippocampus (CA3 → CA1 Schaffer input) Memory retrieval from stored patterns
Fast gamma (60–100 Hz) Driven by EC input (MEC → hippocampus) Encoding of new information

Theta-gamma coupling: Within each theta cycle, multiple gamma cycles are nested. This nesting allows multiple distinct items to be represented in sequence within a single theta cycle — each gamma sub-cycle carries one item. A theta cycle with 7 nested gamma cycles can represent a sequence of 7 items. This is the brain's working memory buffer — the mechanism by which multiple pieces of information are held and sequenced simultaneously.

The coupling strength between theta and gamma correlates with memory performance across individuals. More tightly coupled = better encoding and retrieval.

Sharp-Wave Ripples (SWRs) — 80–200 Hz

SWRs are bursts of high-frequency oscillation (ripples, ~150 Hz) superimposed on slower sharp waves. They occur during rest, quiet wakefulness, and slow-wave sleep (NREM). They are absent during active theta-driven exploration.

The mechanism: A subset of CA3 pyramidal cells fire synchronously and spontaneously, driven by their strong recurrent connections. This synchronous CA3 burst propagates via Schaffer collaterals to CA1, causing a brief ~80ms burst of rapid CA1 oscillation.

What they do:

  1. Memory replay: During SWRs, the sequence of neurons that fired during a recent experience replays at 10–20× compressed speed. A 10-minute maze run is replayed in ~1 second. This compressed replay is the mechanism of offline memory consolidation.
  2. Selective consolidation: Not all experiences are replayed equally. Rewarded experiences, surprising events, and emotionally significant moments generate more robust SWR-associated replay. This acts as a priority filter — the brain selects which experiences to consolidate based on their significance.
  3. LTP induction: The synchronous CA3→CA1 firing during SWRs, combined with the dendritic depolarization of the sharp wave, induces LTP at CA3→CA1 synapses. This literally strengthens the synaptic weight pattern of the replay experience.
  4. Systems consolidation: During SWRs, hippocampal CA1 output is coordinated with slow oscillations in the prefrontal cortex and neocortex, creating windows in which hippocampal patterns are "transferred" to neocortical storage.

9. Neuroplasticity — How Connections Change

Neuroplasticity is the general term for the brain's ability to change its structure and function in response to experience. There are multiple mechanistically distinct forms.

Long-Term Potentiation (LTP) — Strengthening

LTP is the most-studied synaptic mechanism for memory. Discovered by Timothy Bliss and Terje Lømo in 1973, it is a long-lasting increase in synaptic efficacy following high-frequency stimulation.

Molecular mechanism (Hebbian LTP):

  1. A presynaptic neuron fires, releasing glutamate.
  2. Glutamate binds to AMPA receptors on the postsynaptic membrane, causing a small depolarization.
  3. If the postsynaptic cell is simultaneously strongly depolarized (by other inputs), NMDA receptors unblock (the Mg²⁺ block is removed by depolarization) and allow Ca²⁺ to enter.
  4. Ca²⁺ influx activates CaMKII (calcium/calmodulin-dependent protein kinase II), which:
    • Phosphorylates existing AMPA receptors, increasing their conductance.
    • Triggers insertion of additional AMPA receptors into the synapse.
    • Over longer timescales, activates gene transcription to grow new dendritic spines.
  5. Result: the synapse is now stronger — the same presynaptic signal produces a larger postsynaptic response.

Hebb's Rule: "Neurons that fire together, wire together." LTP is the molecular implementation of Hebbian learning. The NMDA receptor acts as a coincidence detector — it only unblocks and allows Ca²⁺ entry when both presynaptic activity (glutamate binding) and postsynaptic depolarization (from other simultaneous inputs) co-occur. This conjunction requirement is why correlated activity — but not uncorrelated activity — strengthens connections.

Long-Term Depression (LTD) — Weakening

LTD is the complementary process: long-lasting decrease in synaptic efficacy following low-frequency stimulation or asynchronous activation. It removes memories and reduces noise. The molecular mechanism is broadly the reverse of LTP: lower Ca²⁺ influx activates phosphatases (rather than kinases), leading to AMPA receptor removal from synapses.

During SWR-associated replay, LTD occurs at synapses of irrelevant memory traces (reducing their signal), while LTP occurs at synapses of the replayed trace (strengthening them). This sharpens the signal-to-noise ratio of stored memories.

Spike-Timing-Dependent Plasticity (STDP)

STDP is a more refined form of Hebbian plasticity. The direction and magnitude of weight change depends on the precise millisecond timing of pre- and postsynaptic spikes:

  • Pre before post (causal, within ~20ms): LTP — the presynaptic cell's activity predicts the postsynaptic cell's activity; strengthen the connection.
  • Post before pre (anti-causal): LTD — the postsynaptic cell fired before the presynaptic cell; the connection was not causal; weaken it.

STDP is the neural implementation of temporal causality detection — the brain literally learns which neurons cause the firing of others based on precise timing. This mechanism is key to how the hippocampus learns temporal sequences (A causes B causes C) rather than just co-occurrence.

Behavioral Timescale Synaptic Plasticity (BTSP)

A newer mechanism (identified ~2019), BTSP operates on second-long timescales rather than millisecond STDP timescales. A single strong input at a behavioral timescale can create a lasting "plateau potential" in a dendrite that induces plasticity over a ~1-2 second window. BTSP is particularly important for encoding spatial context — it allows a single pass through an environment to create strong place-cell representations, without needing repeated exposures.

BTSP helps explain how a salient event can alter place-cell representations after limited exposure. Whether a single event produces durable learning depends on the circuit and experimental conditions.

Structural plasticity — dendritic spines

Beyond synaptic weight changes, neurons physically grow and retract dendritic spines (small protrusions that form the postsynaptic membrane of most excitatory synapses). Strong LTP leads to spine growth (adding new connection surface area). LTD leads to spine shrinkage or retraction. Over weeks and months, structural changes encode the consolidated version of a memory.

Metaplasticity — the plasticity of plasticity

Metaplasticity is the modulation of the threshold for LTP/LTD induction. If a neuron has recently been very active, its threshold for LTP induction rises (making further LTP harder to induce) and its threshold for LTD falls. If it has been relatively quiescent, the reverse occurs. This homeostatic mechanism prevents runaway potentiation and keeps neurons in an operating range where they can still discriminate between important and unimportant inputs.

10. Trajectory Creation — How the Brain Chains Memories Into Sequences

The brain can retrieve sequences, paths, and trajectories through memory space, not only isolated facts.

Place cells and cognitive maps

Place cells (CA1, CA3) are neurons that fire specifically when an animal occupies a particular location in an environment. Each place cell has a place field — a roughly circular region of space in which it fires. Together, the population of place cells forms a cognitive map of the environment.

Key properties:

  • Place fields are allocentric (world-centered), not egocentric (body-centered).
  • They remap entirely when the animal enters a new environment (global remapping) or when task demands change significantly (partial remapping).
  • They can represent conceptual spaces (abstract task states, social hierarchies, decision trees) in addition to physical spaces.

The cognitive map as a general memory structure

The discovery of place cells (John O'Keefe, Nobel Prize 2014) revealed that the hippocampus constructs not just spatial maps but relational maps — structures that encode the relationships between elements of an experience. "Where," "when," "what," and "who" are all mapped in the hippocampal-entorhinal system using related cell types:

Cell type What it encodes Location
Place cells Location in environment CA1, CA3
Grid cells Abstract metric space MEC
Head direction cells Which way you're facing MEC, subiculum
Border cells Walls and boundaries MEC
Time cells Elapsed time within an episode CA1, EC
Object-vector cells Distance and direction to specific objects EC, subiculum
Concept cells Abstract concepts, people, ideas Human MTL

The time cells deserve special mention: neurons in CA1 and the entorhinal cortex fire at specific moments within an unfolding episode, regardless of spatial location. They create a neural timeline of events, with each time cell acting as a "timestamp" marker. This is the biological mechanism for temporal sequencing of episodic memories — remembering not just that A and B happened, but that A happened before B, and by roughly how long.

Theta sequences — the compressed future

During active behavior, within each theta cycle (~125ms), place cells fire in sequences that represent a trajectory ahead of the current position. As an animal approaches a choice point, different theta cycles represent different possible paths (alternating left-right in mazes), as if mentally simulating the options.

This is the neural correlate of lookahead planning — evaluating multiple future trajectories before committing to one. The sequence is generated by the EC grid cells providing a "look-ahead sweep" of the grid, which then drives place cell sequences via the DG and CA3 attractor system.

Reverse replay: At the end of a rewarding experience, or during rest, hippocampal neurons replay the trajectory in reverse — from reward location back to start. This reverse replay is thought to propagate reward value backwards through the sequence, teaching the animal which prior states led to the reward (the neural basis of temporal credit assignment in reinforcement learning).

Sharp-wave ripple replay — the memory consolidation trajectory

During SWRs (offline periods), hippocampal neurons replay entire trajectories in compressed form at 10–20× speed. Crucially:

  1. Awake replay is prospective: Before an experience, neurons can replay likely future trajectories (preplay), suggesting the brain uses stored knowledge to plan.
  2. Post-experience replay is retrospective: After a successful experience, the trajectory that led to the outcome is replayed, preferentially if it included reward or surprise.
  3. Replay is not random: Experiences that led to reward, were novel, or were emotionally salient are replayed more frequently and for longer. This is the brain's selection mechanism — choosing which trajectories to consolidate into long-term memory.

The Entorhinal Cortex as a trajectory navigator

The EC's sequential firing structure (time cells + grid cells) provides a global coordinate system that can chain hippocampal memories into ordered sequences. EC provides the "next step" signal: given current state X, which grid/place/time cell pattern should be active next?

11. Memory Consolidation — From Hippocampus to Neocortex

The standard consolidation theory (SCT)

Early theories of consolidation held that the hippocampus stores memories initially, then gradually transfers them to neocortex over weeks to years. Once fully consolidated, memories become hippocampus-independent. Evidence: remote memories (years old) are often spared in hippocampal amnesics like H.M., while recent memories are lost.

The Multiple Trace Theory (MTT)

MTT revises the standard theory: episodic, contextual memories (rich, vivid memories with spatial and temporal detail) remain hippocampus-dependent permanently. What gets transferred to neocortex is a semantic gist — the extracted, decontextualized facts stripped of their episodic context. H.M. could still know facts but could not remember the experience of learning them.

Complementary Learning Systems (CLS) — addressed in §14

The mechanisms: how consolidation actually happens

System consolidation (hippocampus → neocortex):

  1. During NREM sleep, the hippocampus generates SWR events (~0.5–2Hz).
  2. Each SWR reactivates a hippocampal memory trace.
  3. The hippocampal output is coordinated with slow oscillations in PFC (0.5–1Hz) — specifically, SWRs occur preferentially during the "up state" of the slow oscillation, when cortical neurons are maximally excitable.
  4. Also nested within this: sleep spindles (12–15 Hz) in the thalamo-cortical system provide a window for LTP in neocortical synapses.
  5. The hippocampal pattern reactivated during SWRs is fed to the neocortex, inducing Hebbian changes in neocortical synapses.
  6. After many replay events over many sleep cycles, the neocortex has built its own representation of the information — and the hippocampus is no longer required to retrieve it.

Synaptic consolidation (within synapses):

  • Immediate (minutes): Post-translational modifications — phosphorylation of existing AMPA receptors.
  • Hours: Local protein synthesis at the synapse — new AMPA receptors are inserted.
  • Days: Spine growth, axonal sprouting, structural remodeling.
  • Weeks–months: Full synaptic consolidation, integration into established cortical circuits.

Synaptic tagging and capture: A synapse that has received a weak stimulus (insufficient for late-phase LTP) can still undergo late-phase LTP if a "flag" (the synaptic tag) is set and a strong stimulus elsewhere in the neuron generates plasticity-related proteins (PRPs) that get captured by the tagged synapse. This mechanism allows the neuron to "associate" a weak input with a strong one across a timewindow of hours — the biological basis of binding distinct events that co-occur.

12. Engrams — The Physical Trace of a Memory

What an engram is

The term "engram" (proposed by Richard Semon in 1904) refers to the physical change in the brain that constitutes a stored memory. For decades it was theoretical. Modern optogenetic and calcium-imaging tools have allowed engrams to be directly identified, manipulated, and even created artificially.

Memory Index Theory

The most influential current theory of hippocampal engrams is the Memory Index Theory (Teyler & DiScenna, 1986; updated repeatedly since):

  1. During encoding, a subset of neurons across the neocortex is activated by the experience (the cortical pattern).
  2. The hippocampus encodes not the full experience itself but an index — a compressed pointer to the cortical pattern.
  3. During retrieval, a partial cue activates the hippocampal index, which then reinstates the original cortical activation pattern.
  4. This reinstatement of the original cortical pattern is the memory experience.

Evidence: hippocampal inactivation during retrieval prevents neurons that were active during learning from being reactivated in the cortex — it disconnects the index from the cortical representation.

Two distinct neural populations exist in CA1:

  • c-Fos+ (engram cells): Fire in an on-off, context-specific pattern. Represent the contextual identity (the "index"). These are the engram.
  • c-Fos- (place cells): Provide stable spatial information. These are the map.

Engram competition and updating

Multiple memories can share neurons (overlapping engrams). When memories overlap too much, interference occurs. When a memory is reactivated, it becomes temporarily labile (a process called reconsolidation) and can be updated, strengthened, or even erased. This is the biological basis for:

  • Memory updating: Reactivation can make a memory susceptible to modification when new information is present.
  • Memory interference: Similar or overlapping traces can compete during recall.

13. Adult Neurogenesis — Structural Plasticity in the DG

The dentate gyrus is one of only two brain regions (the other being the olfactory bulb) where new neurons continue to be generated in the adult brain.

The lifecycle of a new neuron in the DG

  1. Proliferation: Neural stem cells in the subgranular zone of DG divide.
  2. Differentiation: Daughter cells differentiate into immature granule cells (~2–4 weeks).
  3. Integration: Immature neurons extend dendrites toward the molecular layer (receiving EC input) and axons toward CA3.
  4. Maturation: Over 4–8 weeks, they integrate into the DG circuit, become less hyperexcitable, and acquire standard granule cell properties.
  5. Survival or apoptosis: Only ~50% of new neurons survive long-term. Survival is promoted by:
    • Learning and cognitive activity
    • Exercise (dramatically increases neurogenesis)
    • Environmental enrichment
    • BDNF (brain-derived neurotrophic factor)
    • Reduced stress (chronic stress severely suppresses neurogenesis)

What new neurons do functionally

Young adult-born neurons have a unique property: they are hyperexcitable and have lower LTP thresholds (they can be potentiated by weaker stimuli). This makes them excellent at encoding new, potentially conflicting information into the DG without disrupting existing representations.

They are specifically important for pattern separation at fine scales — distinguishing between very similar events (same place, different day; same people, different context). They contribute to the sparsification of DG activity by activating local inhibitory interneurons when stimulated, suppressing neighboring granule cells.

Neurogenesis and forgetting: Paradoxically, increasing neurogenesis also increases forgetting of old memories. New neurons integrating into the DG circuit overwrite some of the old sparse codes, erasing old episodic details while preserving semantic generalizations. This is a feature, not a bug: it clears out overly detailed episodic memories that are no longer adaptive, while preserving important structural knowledge.

14. Complementary Learning Systems (CLS) Theory

First proposed by McClelland, McNaughton, and O'Reilly (1995), CLS theory is one of the most influential frameworks for understanding why memory requires two systems.

The core insight: catastrophic interference

Artificial neural networks that learn by gradient descent suffer from catastrophic interference (also called catastrophic forgetting): when trained on task B after task A, learning on B overwrites the weights needed for task A, destroying task A performance entirely. Biological brains don't do this — humans can learn thousands of new facts without forgetting their childhood memories.

The solution CLS proposes: two complementary systems with opposite properties.

Property Hippocampus Neocortex
Learning speed Fast (one-shot) Slow (requires many exposures)
Representation style Sparse, orthogonal (pattern-separated) Dense, overlapping, distributed
Memory type Episodic (specific events, rich context) Semantic (general knowledge, abstract facts)
Interference handling Avoids it via sparsity Integrates across episodes to extract structure
Biological mechanism Hebbian LTP via NMDA in DG/CA3 Gradual weight updates via interleaved replay

How the two systems interact

The hippocampus rapidly encodes individual experiences as crisp, contextualized episodic memories. Over many sleep cycles, hippocampal replay events interleave new experiences with old ones in the neocortex. This interleaved replay allows the neocortex to slowly extract the common structure across many episodes — building semantic knowledge that generalizes across contexts.

The neocortex does not store the episode itself; it stores the generalized pattern (the gist). The hippocampus retains the episodic index.

Why replay is interleaved (not blocked)

McClelland et al. showed computationally that if you train the neocortex on new experiences all at once (blocked training), you get catastrophic interference. If you interleave new experiences with replays of old ones (interleaved training), the neocortex can integrate new information without forgetting old. This is exactly what SWR-driven replay achieves during sleep.

15. Procedural Memory and the Basal Ganglia — The Other Memory System

For completeness: the hippocampus is the substrate for declarative memory (explicit, consciously accessible facts and episodes). A second, distinct system handles procedural memory (implicit, skill-based, "how-to" knowledge that is not consciously accessible).

System Substrate Memory type Examples
Declarative Hippocampus + MTL Episodic + Semantic Remembering your first day at work; knowing Paris is the capital of France
Procedural Basal ganglia + cerebellum Skill + habit Riding a bike; typing; reaching for a glass without thinking

The basal ganglia as a habit learner

The basal ganglia (striatum, substantia nigra, globus pallidus) implement reward-based reinforcement learning at the neural level. The key mechanism:

  • Dopamine signals the difference between expected and received reward (the reward prediction error).
  • Dopamine release in the striatum modulates long-term potentiation at cortico-striatal synapses, strengthening the connection between the current state and the action that led to reward.
  • Over repeated successful trials, the action sequence becomes encoded as a habit — a chunked motor program that fires automatically in the appropriate context, bypassing deliberate planning.

The HIP/BG distinction maps onto the explicit/implicit memory distinction: the hippocampus stores "I know that X leads to Y" (declarative); the basal ganglia store "when X happens, do Y" without explicit knowledge of why (procedural habit).

Skill learning → habit chunking → automaticity

The progression in learning a new skill:

  1. Explicit phase: Each step requires conscious attention; hippocampus active; slow and effortful.
  2. Associative phase: Steps become more automatic; working memory load decreases; BG synaptic weights strengthening.
  3. Autonomous phase: The skill is a "chunk" — a single BG program that fires as a unit, consuming almost no working memory.

The shift from effortful practice to an automatic habit is associated with changing contributions from hippocampal and basal-ganglia systems.
